# 🃏 In-Game Cards Reference

This document lists all available cards in Crypto Cyber Survivors, categorized by their rarity tier.

## 📊 Stat System Overview

| Stat | Effect | Cap |
| :--- | :--- | :---: |
| **Damage** | Raw damage per projectile | - |
| **Speed** | Movement speed | 15 |
| **Fire Rate** | Attacks per second | 20/sec |
| **Crit Chance** | % chance for 2x damage | 95% |
| **Luck** | Gem drop quality & bonus gems | 20 |
| **Lifesteal** | % chance to heal on kill | 50% |
| **Magnet** | Gem collection range | - |

## 📈 Stat Interactions

### Luck Effects
- **Rare Gem Chance:** `5% + (luck × 3%)` (capped at 50%)
- **Bonus Gem Chance:** `luck × 10%` (capped at 50%)
- **Gem Value Bonus:** `+luck%` extra XP

### Lifesteal Effects
- **Proc Chance:** Based on lifesteal stat (capped at 50%)
- **Heal Amount:** 3 HP per normal kill, 8 HP per whale kill
- **Note:** Only heals up to max HP

### Crit Effects
- **Crit Chance:** Pure `critChance` stat (luck does NOT affect crit)
- **Crit Damage:** 2x base damage
- **Super Crit:** 20% of crit chance, deals 4x damage
