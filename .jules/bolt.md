## 2024-04-18 - Optimized SpatialGrid.clear() Map cleanup
**Learning:** In a high-frequency loop like 60 FPS update, indiscriminately clearing the entire Map using `grid.clear()` after iterating over it forces standard Arrays in the object pool to be completely reallocated on standard insertions each frame when keys are repopulated, creating unnecessary GC pressure. However, completely avoiding `clear` and letting maps grow unbounded also harms lookups.
**Action:** Implemented a hybrid clearing strategy in `SpatialGrid.clear()` where only cells that were empty in the *previous* frame (`cell.length === 0`) are returned to the object pool and have their keys deleted (`map.delete(key)`), whereas active cells simply have their length reset to 0 but remain in the map. This limits map size while keeping fast array reuse for populated areas.
