## 2024-05-14 - Replace forEach with standard for loops in high-frequency physics systems
**Learning:** Closure allocations from `Array.prototype.forEach` (and similar higher-order array methods) create unnecessary Garbage Collection (GC) pressure when running continuously in 60 FPS update loops like `MovementSystem.ts`. While this GC pressure might seem small per frame, it aggregates into noticeable stutter over time, specifically during intense combat scenarios with many entities (particles, bullets, enemies).
**Action:** Always prefer standard `for (let i = 0, len = arr.length; i < len; i++)` loops in engine update ticks to enforce a zero-allocation contract. Guard loop variables with `if (entity === undefined) continue;` when dealing with sparse or pooled object arrays to prevent runtime TypeErrors.
