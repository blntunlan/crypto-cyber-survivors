## 2024-05-24 - Zero-Allocation Loop Translation In High-Frequency Update Loops
**Learning:** High-frequency game update loops (e.g., 60 FPS object tracking) can suffer from garbage collection (GC) pressure when using Array.prototype.forEach(), which allocates closure functions on every call. Replacing them with standard `for (let i = 0, len = arr.length; i < len; i++)` loops removes these allocations, resulting in more stable frametimes.
**Action:** When working in `MovementSystem.ts`, `CollectionSystem.ts`, or similar core tick loops, identify uses of `forEach` on rapidly iterating arrays (`pool.activeEnemies`, `pool.activeBullets`, etc.) and replace them with standard indexed loops. Remember to translate `return;` inside the original `forEach` callbacks to `continue;` in the `for` loops to preserve logic correctly.
