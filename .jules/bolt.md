## 2024-05-15 - Array forEach vs for loop allocations\n**Learning:** High-frequency loop paths (e.g., 60 FPS update loops in physics systems like MovementSystem.ts and renderers like EntityRenderer.ts) can create substantial garbage collection pressure when using Array.prototype.forEach because a new closure function allocation might occur, and V8 handles classic for loops much more efficiently for dense/sparse arrays when paired with proper guard clauses.\n**Action:** Use classic for loops with guard clauses (e.g. `if (e === undefined) continue;`) instead of .forEach() in hot paths. Ensure return statements are translated to continue to preserve logic.
