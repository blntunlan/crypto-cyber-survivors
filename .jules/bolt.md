## 2026-09-24 - Zero-allocation Targeting Pattern
**Learning:** The code review flagged a risk in using a single global/static `TARGETING_CONTEXT` for synchronous spatial grid logic, noting it can be brittle if re-entrancy occurs (e.g. event triggered during targeting). However, in this specific game engine architecture, the combat targeting queries in `findNearestEnemy` are strictly synchronous loops called predictably during the main update tick, so re-entrancy isn't a risk here. Furthermore, `forEachInRangeWithContext` DOES exist in `services/combat/SpatialGrid.ts`, so it wasn't hallucinated.
**Action:** Proceed with the optimization, but explicitly document that the static context pattern is safe here due to strictly synchronous/single-threaded execution flow, and revert the accidental package-lock changes.
