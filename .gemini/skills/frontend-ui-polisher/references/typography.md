# Typography & Font Hierarchy

The Crypto Survivors project uses a specific set of fonts to maintain its cyberpunk aesthetic.

## Font Registry
- **Display**: `"Audiowide"` (Headings, titles, high-impact numbers)
- **Primary**: `"Chakra Petch"` (Standard body text, labels, descriptions)
- **Secondary**: `"Michroma"` (Subtitles, meta-info)
- **Mono/Numbers**: `"Quantico"` (Code, timers, stats, score)

## Size Scale
| Element | Font | Size (Desktop) | Size (Mobile) | Weight |
|---------|------|----------------|---------------|--------|
| H1      | Display | 3.5rem | 2rem | Bold |
| H2      | Display | 2.5rem | 1.75rem | Bold |
| H3      | Display | 1.75rem | 1.5rem | Semi-Bold |
| Body    | Primary | 1rem | 0.875rem | Regular |
| Labels  | Secondary | 0.875rem | 0.75rem | Regular |
| Stats   | Mono | 1.25rem | 1rem | Bold |

## Guidelines
1. **Never use generic fonts**: Always fallback to the specific theme fonts.
2. **Text Glow**: Use `text-shadow: 0 0 10px rgba(0, 255, 255, 0.5)` for primary headings in Cyberpunk theme.
3. **Line Height**: Maintain 1.5 for body text for readability.
4. **Letter Spacing**: Display fonts benefit from slight tracking (e.g., `letter-spacing: 0.05em`).
